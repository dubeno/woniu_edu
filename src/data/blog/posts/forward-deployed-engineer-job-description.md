# Forward Deployed Engineer 是什么？JD 关键词拆解 + 上岸路径

> 蜗牛AI · FDE 系列 · 求职专栏

## FDE 是什么？

Forward Deployed Engineer（前线部署工程师）是把 AI / 软件能力**直接交付到客户现场**的角色。OpenAI、Anthropic、Palantir、Scale AI、Cohere 都设这条线。

| 角色 | 主要工作 | 核心指标 |
|------|---------|---------|
| SDE | 公司内部产品 | 内部业务指标 |
| FDE | 客户 / 落地 | 客户续约 / 业务结果 |
| Solutions Engineer | 售前 + POC | 合同转化率 |
| Tech Lead | 团队工程 | 系统稳定性 |

## 典型 JD 关键词拆解

- **customer-facing / customer engineering**：客户第一线
- **stakeholder management**：能推动跨团队干系人
- **rapid prototyping → production**：3 周 PoC → 3 月上线
- **POC ownership**：从需求到交付的端到端 owner
- **enterprise integration**：SSO / VPC / 合规
- **hands-on**：70% 编码，30% 沟通
- **bias for action**：先做再讨论

## OpenAI / Anthropic / Palantir 在招什么样的 FDE

- **OpenAI**：FDE 倾向 3–6 年经验，看企业级 LLM 集成 / 推理优化
- **Anthropic**：Solutions Engineering 偏产品演示 + 集成
- **Palantir Foundry**：看数据集成 / Ontology / 客户工作流
- **Scale AI**：FDE 偏 RLHF / 数据闭环
- **Cohere**：Solutions Engineering 偏企业 NLP 集成

> **共同点**：要能写代码 + 跟客户高层沟通 + 拆需求并交付。

## 简历没有大厂交付经验怎么办？

三步把经验包装成 FDE 叙事：
1. **找到客户视角的项目**：哪怕是学校 / 实验室 / 开源项目，只要外部用户用过就算
2. **重写项目段**：用「场景 + 角色 + 指标 + 技术亮点」三行法
3. **加一行交付物**：可演示的 URL / 视频 / 截图 → 面试中点开

## FDE 面试流程

| 段 | 内容 |
|----|------|
| Recruiter | 背景 / 客户沟通经验 |
| Technical Coding | Python / SQL / System Design |
| Customer Simulation | 模拟客户场景拆需求 |
| System Design | 端到端 POC 架构设计 |
| Cross-functional | 跟 PM / Sales 模拟共事 |
| Onsite / VP | 视野 / 文化 |

> **核心考察**：你能否让客户持续续约 / 扩展用例。

## 上岸路径

- **0–2 年**：从 1–2 个客户级项目入手，能交付 POC
- **2–5 年**：积累 3+ 行业 PoC，能拆复杂需求
- **5+ 年**：可以做 Playbook，跨客户复制成功模式

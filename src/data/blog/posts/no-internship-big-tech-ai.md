# 无大厂实习怎么进 AI 大厂？3 个「可演示交付物」补项目段

> 蜗牛AI · 转码 / NG 系列 · 求职专栏

## 痛点

NG / 转码背景最常见的问题：
- 简历没有顶级实习
- 不知道做什么 AI 项目才有说服力
- 不知道怎么把项目讲成「能上线」

## 3 个可演示交付物

### 1. 端到端 RAG 知识库

- 选一个真实场景：某开源项目 FAQ / 某公司财报 / 某行业 SOP
- 完整跑通：爬取 → 清洗 → Embedding → 检索 → 评估
- **演示物**：可访问的 URL + 截图

### 2. Agent POC

- 选一个真实任务：自动研究、自动客服、自动 Code Review
- 完整跑通：工具注册 → 状态机 → 评估 → 失败重试
- **演示物**：录屏 / Demo Notebook

### 3. 推理优化复现

- 选一个开源模型：LLaMA / Qwen / Mistral
- 完整跑通：量化 → 推理服务 → 压测 → 成本对比
- **演示物**：压测报告 + 数字结论

> 三个里挑一个做透，比每个做一点好。

## 简历项目段三行公式

```
项目名 | 你的角色
场景 + 指标 + 量化结果（一行）
技术亮点：模型 / 系统 / 工程 至少一层有可量化贡献
```

> 例子：某 RAG 知识库 | 主程
> 把内部 200+ FAQ 检索准确率从 62% 提升到 91%，P95 延迟 600ms
> 引入 Hybrid Search + Re-rank + 评估流水线，单测覆盖率 80%

## 投递策略

- **校内 / 实验室 / 开源**：补一段「外部用户用过」的叙事
- **个人项目**：补一段「可演示」交付物
- **比赛 / 黑客松**：补一段「团队协作 + 时间压力」

> 弱化实习段，强化项目段。
